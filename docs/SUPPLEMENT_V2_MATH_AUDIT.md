For X=LZ, Z independent standard normal, lower bounds -infinity and upper bounds b, define c_i=Phi((b-sum_{j<i}L_ij z_j)/L_ii). Substitute z_i=Phi^-1(u_i c_i) in successive conditional integrals. Each substitution contributes c_i to the Jacobian-weighted probability. The last normal integral is performed analytically, so f(u)=product_i c_i is on [0,1]^(m-1), with 0<=f<=1 known before sampling. No empirical sample range is used. Natural order is fixed. This is an application transform, not a new probability algorithm or claimed innovation.

For equicorrelation Sigma=(1-rho)I+rho 11^T, zero-indexed L_jj=sqrt((1-rho)(1+j rho)/(1+(j-1)rho)), L_ij=rho sqrt((1-rho)/((1+(j-1)rho)(1+j rho))) for i>j. Off-diagonal entries below column j are constant. Therefore the conditional sum updates by adding L_(j+1),j z_j; no full matrix multiplication is necessary. Multiplication verifies LL^T=Sigma; the validation additionally checks an independent NumPy dense Cholesky and pointwise dense recursion, including rho=0. For rho=0 the product is Phi(b)^m. For rho>0, u_j=0 maps to z_j=-infinity and subsequent masses tend to one. With the declared positive rho and bounds no mixed-sign infinities arise. No finite endpoint clipping is introduced.

Independently, X_i=sqrt(rho)Z+sqrt(1-rho)epsilon_i, hence probability=integral phi(z)Phi((b-sqrt(rho)z)/sqrt(1-rho))^m dz. ## Rare-pilot mechanism (a priori, zero integrand calls)

For a binary event with probability p and Kh0 initial pilot points having uniform marginals, P(any positive)<=sum P(positive)=Kh0p, regardless of dependence within a net. Thus P(all zero)>=max(0,1-Kh0p), giving nominal lower bounds .936/.9936 for K16,h0=4 and p10^-3/10^-4. The finite-grid statement uses p_grid instead of p_continuous. This is an elementary union-bound diagnostic, not a new confidence theorem or an empirical event-frequency estimate.

`scripts/audit_zero_pilot_mechanism.py` deterministically evaluates the unchanged selector with zero pilot matrices for K8/16/32, N16384/65536, both A02/PLUGIN_STAGE (12 settings), no integrand evaluations. All select n1 and stop at depth4. The check applies only to these declared constants.
